# Python

## Historie

Python je **populární** programovací jazyk. Jeho syntaxe je *čitelná* a stará verze 2 je dnes ~~podporovaná~~ zastaralá.

### Významné události

- Vydání Pythonu 1.0 v roce 1994
- Vydání Pythonu 2.0 v roce 2000
  1. Přidání list comprehension
  2. Přidání garbage collectoru
- Vydání Pythonu 3.0 v roce 2008

### Osobnosti

1. Guido van Rossum
2. Barry Warsaw
3. Raymond Hettinger
