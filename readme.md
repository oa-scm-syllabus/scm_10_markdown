# PVA2 - Programování a vývoj aplikací
## Cvičení 01: Markdown

Cílem cvičení je procvičit si syntaxi GitHub Markdown na dvou navazujících úkolech. Syntaxe jednotlivých prvků je shrnutá v [prezentaci k přednášce](https://oa-scm-syllabus.github.io/scm_prednasky/10_markdown/) — pokud si nejste jistí zápisem konkrétního prvku, podívejte se tam.

## Úkoly

| Úkol | Zadání | Výstupní soubor |
|------|--------|------------------|
| A – Pevné zadání | [ukol-a-projekt.md](ukol-a-projekt.md) | `project_readme.md` |
| B – Volné téma | [ukol-b-volne-tema.md](ukol-b-volne-tema.md) | `it_markdown_practice.md` |

- **Úkol A** navazuje na `project_readme.md`, který je v tomto repozitáři už připravený jako kostra se značkami `<!-- TODO -->`. Doplňte do něj obsah podle zadání tak, aby všechny značky zmizely.
- **Úkol B** vytvoříte od nuly jako nový soubor `it_markdown_practice.md` na libovolné IT téma dle vlastního výběru.

## Odevzdání

1. Doplňte/vytvořte oba soubory (`project_readme.md`, `it_markdown_practice.md`) v tomto repozitáři.
2. Commitněte a pushněte změny do svého GitHub repozitáře.

## Automatická kontrola a zpětná vazba

Po každém pushi se vaše soubory automaticky zkontrolují (hlídá se přítomnost
požadovaných prvků Markdownu, ne obsah ani téma). Výsledek najdete
v **pull requestu „Feedback“** ve svém repozitáři: komentář s body za každý
úkol, seznamem očíslovaných požadavků (splněno / nesplněno) a nápovědou,
co chybí. Komentář se po každém dalším pushi přepíše aktuálním stavem,
historie pokusů je v něm sbalená dole.

Do téhož pull requestu můžete psát dotazy k hodnocení — vidí ho vyučující.
