# Úkol A: README fiktivního projektu "TaskFlow"

Představte si, že jste autorem CLI nástroje **TaskFlow** — jednoduché aplikace pro správu úkolů z příkazové řádky. Vaším úkolem je dopsat jeho `project_readme.md` tak, aby vypadal jako skutečné README reálného open-source projektu.

V repozitáři už je připravená kostra souboru `project_readme.md` se značkami `<!-- TODO: ... -->`. Doplňte obsah podle bodů níže tak, aby v souboru nezůstala žádná TODO značka.

## Povinné prvky

1. **Nadpisy** — H1 s názvem projektu, alespoň dvě úrovně (H2/H3) pro jednotlivé sekce.
2. **Formátování textu** — v popisu projektu smysluplně použijte tučný text, kurzívu i přeškrtnutý text (např. u zastaralé funkce).
3. **Obsah s kotvami** — seznam odkazů na sekce níže v dokumentu pomocí anchor odkazů (`[Sekce](#sekce)`).
4. **Nečíslovaný seznam** — minimálně 4 funkce nástroje, u jedné z nich vnořený podseznam.
5. **Číslovaný seznam** — minimálně 3 kroky instalace.
6. **Kód** — blok kódu se zvýrazněním syntaxe (bash) s instalačním/spouštěcím příkazem a alespoň jeden inline kód (např. název parametru) v textu.
7. **Obrázky** — jeden inline obrázek (např. badge) a jeden reference obrázek.
8. **Odkazy** — jeden inline odkaz a jeden reference odkaz (např. na dokumentaci).
9. **Tabulka** — tabulka konfiguračních parametrů, minimálně 2 sloupce a 3 řádky.
10. **Citace** — blockquote s ukázkovou reakcí uživatele na nástroj.
11. **Sbalitelný blok** — sekce `<details><summary>` (např. "Řešení častých problémů").
12. **Checkbox seznam** — roadmapa s minimálně 3 položkami, část zaškrtnutá.
13. **Horizontální čára** — oddělující hlavní obsah od patičky.
14. **Poznámka pod čarou** — footnote u informace o verzi nebo licenci.

Přesné znění textů (název funkcí, popisky) je na vás — záleží na tom, aby byly přítomné požadované markdown prvky.
